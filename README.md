# Bookstore Database Management System

## What is this project?
A Python program that manages a bookstore inventory using SQLite. You can add, update, delete, and search for books.

## Features
- Add new books (with ID, title, author, quantity)
- Update book details
- Delete books
- Search books by ID or title
- View all books with author info

## Technologies Used
- Python
- SQLite3
